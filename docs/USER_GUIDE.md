# 纸上回音 · Paper Echoes 使用指南

> **NotebookLM 风格个人博客与声音工坊**  
> 一体化实现：PDF/Word 拖拽解析 + 云端 DeepSeek 长文写作 + 专属声音克隆与播客生成 + 微信公众号一键排版

---

## 一、 快速启动

在本项目根目录下：
- **方式一（推荐 EXE 版）**：双击运行根目录的 **`启动纸上回音(双击启动EXE).bat`**，或直接打开 `dist\纸上回音\纸上回音.exe`。
- **方式二（开发源码版）**：双击运行根目录的 **`启动纸上回音.bat`**。

启动后将弹出一个精致的原生桌面客户端工作台窗口，**零浏览器外壳，完全免命令行干扰**。

---

## 二、 第一次使用：配置云端 API

点击右上角的 **`⚙️ 设置`**：
1. **大模型配置 (DeepSeek)**：
   - **Base URL**：保持默认 `https://api.deepseek.com`。
   - **API Key**：填入您的 DeepSeek API 密钥（以 `sk-` 开头）。
   - **模型名称**：
     - `deepseek-chat`：快速流畅，极佳的专栏笔触（推荐默认）。
     - `deepseek-reasoner`：DeepSeek R1 深度思考模型，逻辑推导与材料剖析极强。
   - 点击 **`⚡ 测试大模型连接`**，看到绿色提示即表示配置成功。
2. **声音克隆 TTS 接口 Key（可选）**：
   - 填入您的云端 TTS Key（如硅基流动 SiliconFlow 或阿里百炼 DashScope）。
   - **注意**：如果您暂时不想填，软件默认内置了高质量微软神经音色（晓晓、云希、云扬），**免 Key 随时可用，开箱即可发声**！
3. 点击 **`保存配置`**，配置会自动持久化在本地。

---

## 三、 四步极简创作闭环

### 步骤 1：投喂材料（支持拖拽）
- 直接从 Windows 资源管理器中将 **PDF、Word (.docx)、Markdown (.md)、TXT** 文件**拖拽**进左侧虚线框；
- 或点击 **`+ 添加文件`** 选择本地文件；
- 软件将自动解析提取全文，并展示每份材料的字数、摘要和勾选框。支持勾选单篇或多篇材料协同创作。

### 步骤 2：设定创作意图
在顶部控制栏微调：
- **风格模板**：
  - 深度科技/商业专栏（视角独到、推导扎实、客观深刻）
  - 生动通识科普（深入浅出、善用生活比喻）
  - 个人叙事随笔（第一人称、温润真诚、有思想余韵）
  - 实战方法论干货（步骤化、避坑指南、可执行度高）
  - 微信公众号爆款（开篇抓人、节奏紧凑、共鸣感强）
- **目标篇幅**：1500 字 / 2500 字（深度长文） / 3800 字 / 5000 字。
- **聚焦方向**：可在输入框补充您的主观要求（如：“重点剖析第 2 节的技术阻碍，结合国内市场给出建议”）。

### 步骤 3：两阶段智能生成
- 点击 **`1. 提炼大纲`**：大模型先行深度研读材料，生成结构化大纲（含标题、核心论点、材料事实出处）。大纲以卡片形式展开，您可以**直接在大纲卡片上打字微调**。
- 点击 **`2. 撰写博客全文`**（或大纲卡片中的「按此大纲撰写正文」）：AI 将严格锚定材料事实，展开为完整深度的 Markdown 长文，并在右侧实时渲染精美排版。

### 步骤 4：沉浸编辑与一键分发
- **划词局部 AI 精修**：在左栏 Markdown 编辑框中用鼠标选中任意一段文字，会弹出悬浮菜单：
  - ✨ **去AI味润色**：剔除陈词滥调与生硬翻译腔，使行文更纯正。
  - 🔍 **丰富扩写**：充实细节展开与论据。
  - ✂️ **精简提炼**：字字珠玑，干练有力。
  - 🗣️ **口语化**：转为大白话对话感。
- **一键微信公众号排版**：点击右上方 **`📋 复制公众号排版`**，软件会将富文本及内联排版样式完整拷贝到剪贴板。打开微信公众号后台直接 `Ctrl + V` 粘贴，标题修饰、底纹、间距立刻就绪！
- **导出与保存**：支持 **`⬇️ 导出 Markdown`** 和 **`💾 保存草稿`**（右上角草稿箱可随时查看和回溯）。

## 四、 声音克隆与专属播客

### 1. 克隆您自己的声音
1. 用手机或电脑录制一段您自己的清晰音频（**10~30 秒即可**，格式支持 `.wav` / `.mp3` / `.m4a`），朗读一段任意文本，尽量在安静环境下录音。
2. 在软件左下方点击 **`🎙️ 克隆声音`** 按钮。
3. 选择您刚才录制的音频文件，输入音色名称（如“船长原声”），并填入音频里所读的文字（填入后复刻精度大幅提高）。
4. 选择克隆提供商（如 SiliconFlow 或百炼），点击 **`✨ 开始克隆并保存`**。
5. 系统将提取声学特征并建立音色档案，自动激活为当前朗读音色！

### 2. 生成专属播客音频
- 在生成完博客正文后，点击右上角的 **`🎙️ 一键转为声音播客`**。
- AI 会先将书面长文转化为节奏明快、生动自然的口播台词。
- 随后调用专属克隆音色流式合成 `.mp3` 音频。
- 底部将弹出沉浸式音频播放栏，支持在线播放、拖动进度条，并可点击 **`⬇️ 下载音频 (.mp3)`** 保存分享！
